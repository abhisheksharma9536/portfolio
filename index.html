04Engineering

How I build systems that hold up in production.

Eight areas I work in, each backed by something I've actually shipped — not a list of buzzwords.

  1. 01

    Backend architecture

    Services with clear responsibilities, connected by APIs. GoodieBag runs on a core Node.js/Express.js backend, and its AI chatbot runs as a separate Python/FastAPI service that integrates with both the backend and the app.

    • Core Node.js/Express.js backend for a 200K+ user marketplace
    • Python/FastAPI AI service alongside it

    Node.js / Express.js / FastAPI / Microservices

  2. 02

    API design & reliability

    REST APIs organized around the product's domains — authentication, catalog, ordering, partner management — with validation middleware, structured error handling and JWT authentication applied consistently across services.

    • GoodieBag REST APIs for four core domains
    • Secure REST APIs for clinical workflows on Avery Telehealth

    REST / JWT / RBAC / Validation

  3. 03

    Database performance

    Performance work that starts at the data layer. On GoodieBag, optimizing PostgreSQL queries and adding targeted indexes for high-concurrency load improved API response time by 40%.

    • 40% API response-time improvement on GoodieBag

    PostgreSQL / Query optimization / Indexing / Data modeling

  4. 04

    Integrations & webhooks

    Treating third-party systems as part of the product. Square and Clover POS integrations with webhook-based sync let partners manage locations, catalog, inventory and orders from their existing POS; Stripe covers checkout, payment webhooks, refunds, failures and payouts.

    • ~90% less partner operational effort on GoodieBag
    • Real-time catalog and inventory sync

    Square / Clover / Stripe / Webhooks

  5. 05

    Cloud & delivery

    Serverless where it fits, and automated, repeatable releases. AWS Lambda functions in Python and Node.js handle file processing and background jobs, S3 stores media, Cognito handles authentication — and services ship in Docker through CI/CD pipelines.

    • Lambda, S3 and Cognito on GoodieBag
    • Docker + CI/CD for automated, consistent releases

    AWS Lambda / S3 / Cognito / Docker / CI/CD

  6. 06

    AI & LLM integration

    LLM features built as real services, not demos. The GoodieBag chatbot is a FastAPI service on the Anthropic Claude API, wired into the backend and the app to answer customer and partner queries. The assistant on this site follows the same grounding principle: it answers only from a structured knowledge base built from this portfolio's content.

    • AI chatbot service for customer and partner queries
    • Three Claude Academy certifications (2026)

    Claude API / Prompt engineering / Structured outputs / MCP

  7. 07

    Cross-platform mobile

    One Flutter codebase for iOS, Android and web — reusable widgets and state management, covering the full journey from store discovery to order tracking.

    • The complete GoodieBag app on three platforms

    Flutter / Dart / State management

  8. 08

    Quality & correctness

    Correctness at every layer: form validation, error handling and logging for healthcare data on Avery Telehealth; AST-level fixes for false-positive detections on Code Analyzer; test cases and TestRail defect tracking for release quality.

    • False-positive fixes for enterprise customers
    • Healthcare data-handling requirements

    Validation / Logging / ASTs / TestRail
